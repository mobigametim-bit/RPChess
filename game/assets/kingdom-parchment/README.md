# RPChess — пергаментная карта (эксперимент PR #190)

## Исходные изображения

В репозитории **112 SVG 128×128 в семи группах по 16 ассетов**:

- `parchment_base_variations/` — грунт/пергамент;
- `forest_clusters/` — леса;
- `mountain_clusters/` — горы;
- `hills_rocks/` — холмы и камни;
- `fog_of_war_shapes/` — туман войны;
- `marsh_wasteland_optional/` — настоящие болота и пустоши (например, `01_pale_marsh.svg`, `03_reeds.svg`, `06_bog.svg`, `08_cracked_earth.svg`);
- `decor_minor_landmarks/` — руины, мосты и ориентиры.

**Важное исправление:** в исходной загрузке болотные и декоративные изображения оказались под неправильными именами, хотя названия папок уже были исправлены. В коммите `98379e1` перенесены *реальные SVG-изображения болот* из файлов с именами орнаментов в `marsh_wasteland_optional/` под правильными именами. Все 16 SVG декоративных рамок/границ из `territory_border_accents_optional/` удалены. Их больше нельзя выбирать ни в игре, ни в Atlas Lab.

## Дороги и владения

Дорожные и речные **модульные SVG** (32 штуки) также удалены. При этом генератор продолжает **алгоритмически рисовать непрерывные дороги и реки** на Canvas по мировым координатам. Границы присоединённых территорий по-прежнему рисуются алгоритмом в Canvas: отдельные декоративные рамки не нужны.

`scripts/build.cjs` генерирует `dist/assets/kingdom-parchment/extra-manifest.json` по реально существующим файлам. В CI контролируются ровно 112 изображений / 7 групп, отсутствие декоративных рамок и корректные имена болот.

## Экспериментальный режим

- Режим «Пергамент» включается независимо от классического режима и не меняет сохранения забега;
- процедурный ландшафт воспроизводится по координатам и seed;
- игровая сетка и ход короля в восемь направлений сохранены;
- Atlas Lab — автономный HTML-инструмент для настройки визуальной генерации; JSON конфигурации переносится в PR отдельно после приёмки;
- **PR #190 остаётся Draft; не сливать в main до приёмки.**
