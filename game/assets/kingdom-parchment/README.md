# RPChess — пергаментная карта (эксперимент PR #190)

Постоянное ядро: **80 SVG в пяти наборах** по 16:
`parchment_base_variations/`, `forest_clusters/`, `mountain_clusters/`,
`hills_rocks/`, `fog_of_war_shapes/`.

**Сегменты `road_segments/` и `river_segments/` удалены** по решению автора.
Их ассеты и процедурные линейные дороги/реки больше не участвуют в рендере.

## Дополнительные авторские ассеты

Поддерживается до **48 новых SVG** (три набора по 16):
болота/пустоши, малые ориентиры и декоративные границы владений.
Фактические имена папок и файлов читаются из содержимого
`game/assets/kingdom-parchment` во время сборки — не нужно подгонять
названия под предварительные предположения.

`scripts/build.cjs` создаёт `dist/assets/kingdom-parchment/extra-manifest.json`.
Рендерер загружает этот каталог, классифицирует добавочные группы по имени
(марш/пустошь, ориентиры/декор, границы) и размещает элементы только на
видимом участке с детерминированными координатами.

**Состояние на момент записи:** на ветке присутствует исходное ядро из
112 SVG, новые 48 ещё не наблюдаются в дереве GitHub. Перед приёмкой
проверить наличие новых трёх папок и реальное количество 128 SVG после
удаления 32 дорожных/речных модулей: **80 + 48 = 128**.

## Механика

- Опциональный режим «Пергамент» с переключением на «Классику».
- Seed и мировые координаты воспроизводят тот же рельеф после перемещения.
- Логическая сетка, встречи, боевые защитники, туман и присоединение не меняются.
- Арт-редактор `Atlas Lab` может импортировать добавочные SVG локально
  и экспортировать настройки в JSON для переноса в игровой генератор.
