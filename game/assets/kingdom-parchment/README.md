# Экспериментальная пергаментная карта RPChess

Это **опциональный** визуальный режим карты Королевства. Он не меняет движение, встречи, экономику и формат сохранений.

## Авторские ассеты

Получен пользовательский архив `png128_svg_vectorized_112_only.zip`: **112 SVG 128×128 px**, семь групп по 16 файлов. Точные имена зарегистрированы в `game/js/kingdom-parchment-core.mjs`.

Папки под `game/assets/kingdom-parchment/`: `parchment_base_variations`, `forest_clusters`, `mountain_clusters`, `hills_rocks`, `road_segments`, `river_segments`, `fog_of_war_shapes`. В каждой должно быть 16 SVG.

Собран готовый архив `RPChess_parchment_112_assets_for_PR190.zip` с полными путями `game/assets/kingdom-parchment/<group>/<file>.svg` без изменения авторских изображений.

**Важно:** GitHub-коннектор принимает текстовые файлы, но не умеет читать локальный ZIP из чата. В PR пока загружены генератор, переключатель, тесты и этот README. SVG должны быть перенесены из подготовленного инсталляционного архива в ветку отдельной загрузкой. Не считать их опубликованными в Cloudflare до отдельной проверки.

## Эксперимент

- Рисование одного сплошного полотна по `run.id` и мировым координатам с кэшем чанков 4×4 клетки.
- Дороги, реки, леса, горы, холмы, базовая бумага и органичный туман; при наличии 112 SVG декоративные элементы подключаются лениво, только на видимом участке.
- Если авторских SVG ещё нет в сборке, используется временная процедурная Canvas-отрисовка. Она нужна для проверки UX и не подменяет финальный художественный набор.
- Туман скрывает неизвестные области без сетки серых квадратов, но все игровые клетки по-прежнему 142×142 px логически.
- Кнопка «Оформление карты: Классика / Пергамент» возвращает прежнюю карту. Настройка хранится в `rpchess.kingdom.visual.v1` отдельно от забега.
- На тестовом стенде параметр `?parchment=1` впервые включает эксперимент (если игрок не сохранял другой выбор).
