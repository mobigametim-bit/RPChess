# 15 — Save System

## Новая схема
Старые Iron Marches saves не импортируются. Reboot начинает новую schema `saveVersion: 1`.

## Минимум
`runSeed`, `runDepth`, `gold`, `supplies`, `roster`, `currentChoices`, `currentEncounter`.

## Правило обновлений
При несовместимом dev-изменении допускается сброс сохранений. До релиза приоритет — корректность тестирования, а не обратная совместимость каждого промежуточного прототипа.

## Позднее
Перед релизом вводятся явные migrations.
