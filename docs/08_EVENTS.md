# 08 — Events

Короткие фэнтезийные текстовые выборы с **моментальным эффектом**.

## Возможные последствия
- получить/потерять золото;
- получить/потерять припасы;
- нанять фигуру;
- тяжело ранить фигуру;
- мгновенно потерять фигуру;
- ничего не получить.

## Тематика
Нежить, гоблины, орки, драконы, ведьмы, демоны, эльфы, гномы, культисты, руины, караваны, могилы, алтари, лесные духи, торговцы, наёмники.

## Запрет
Не строим длинные event chains и политическую систему. Выбор разрешается сразу.
