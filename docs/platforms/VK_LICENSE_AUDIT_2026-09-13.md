## 1. Stockfish 18 — PASS

`THIRD_PARTY_NOTICES.md` identifies the Stockfish runtime distribution, GPLv3 license, and states that production includes:

- `vendor/stockfish/COPYING.txt`;
- `vendor/stockfish/SOURCE.txt`;
- corresponding-source information generated by `scripts/stockfish-assets.cjs`.

The production build treats Stockfish as a separate Web Worker/WASM component rather than relicensing it under RPChess's MIT license.

**Pre-moderation action:** none beyond verifying the files are present in the exact moderation candidate.

## 2. BrahmsGotischCyr — PASS

Repository evidence:

- `game/fonts/BrahmsGotischCyr.otf`;
- `game/fonts/BrahmsGotischCyr_LICENSE.txt` — SIL Open Font License 1.1;
- `game/fonts/BrahmsGotischCyr_COPYRIGHT.txt` — attribution `Sasha Pavljenko`;
- `THIRD_PARTY_NOTICES.md` records the same attribution/license.

The production build copies the font plus its sidecar license/copyright files.

**Pre-moderation action:** none beyond candidate verification.

## 3. Lichess Open Database Puzzles — PASS

`THIRD_PARTY_NOTICES.md` records:

- runtime catalog: `game/js/puzzles/puzzle-catalog.mjs`;
- source: Lichess Open Database Puzzles;
- license: CC0;
- source location: `https://database.lichess.org/#puzzles`.

**Pre-moderation action:** keep the notice in the release repository/candidate documentation.

## 4. Audio — OPEN

The runtime audio owner module uses exactly four music tracks:

- `game/music/echoes_iron_throne_01.mp3`;
- `game/music/echoes_iron_throne_02.mp3`;
- `game/music/echoes_iron_throne_03.mp3`;
- `game/music/echoes_iron_throne_04.mp3`.

The production tree also contains the game SFX used by the runtime, including `game/SFX/win_fanfare.mp3`.

The repository audit found ownership/runtime references, but did **not** find an explicit license/provenance document for those audio files. A filename, commit history, or the fact that RPChess uses a file is not proof of commercial-use rights.

**Owner decision required before moderation candidate is frozen:** confirm the origin and commercial-use rights for these audio files. Once confirmed, add a short record such as `docs/licenses/RPCHESS_AUDIO_PROVENANCE.md` with source/tool/author, date if known, and the basis for commercial use. If any track cannot be cleared, replace it before submission.

## 5. Visual assets — inventory exists; provenance should be centralized

The repository contains asset manifests/audits for production visual content (for example event-asset registers and imported production paths). These are useful for proving which files are intentional production assets, but an import manifest alone does not establish copyright ownership or commercial-use permission.

For first moderation, a practical repository-side record is enough unless VK asks for additional documents:

- distinguish RPChess-original / commissioned / AI-generated / third-party assets;
- record any third-party license or source;
- keep evidence outside Git as needed for contracts/private receipts;
- do not state that an asset is cleared unless its origin is known.

**Current audit status:** no specific conflicting third-party visual license was found during this pass, but this is not equivalent to a complete chain-of-title review for every PNG/JPG.

## Current blockers from this audit

The repository has clear license handling for **Stockfish, the Brahms font and Lichess puzzles**. The concrete unresolved provenance items found in this pass are **music and `win_fanfare.mp3`**. Visual assets need a centralized provenance statement, but no specific contradictory license was found in the current repository audit.
