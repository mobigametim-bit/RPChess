**Целевая схема:**

```text
game/
  js/
    ...общая игровая логика...
    platform/
      platform.mjs
      web-platform.mjs
      vk-platform.mjs

platforms/
  vk/
    vk-hosting-config.json
    README.md

dist/       ← обычный Web build
dist-vk/    ← VK build
```

**Результат этапа:** Web и VK используют одну игру, но имеют разные platform adapters и build targets.

# 7. Решить, что делать с сохранениями в VK v1

- [ ] **[ТЫ]** Если подключаем выплаты/рекламу — зарегистрироваться в Кабинете выплат.
