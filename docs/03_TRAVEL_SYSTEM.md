# 03 — Travel System

## Путешествие без заранее построенной карты
После каждой встречи генерируются ровно три карточки следующего пути.

## Типы
- Шахматная задача
- Стычка
- Сражение
- Событие
- Поселение

## Стартовые веса генерации
- Puzzle 20%
- Skirmish 25%
- Battle 15%
- Event 25%
- Settlement 15%

## Ограничения
- желательно минимум два разных типа среди трёх карточек;
- не выдавать три одинаковых тяжёлых боевых узла;
- после длинной серии боёв допускается мягкое повышение вероятности Settlement;
- система не обязана гарантировать спасение игрока.

Каждый новый набор создаётся только после полного исхода предыдущей клетки.
