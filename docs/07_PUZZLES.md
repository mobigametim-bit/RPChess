# 07 — Puzzles

## Поддерживаемые типы
Мат в 1, мат в 2, мат в 3, комбинации, выигрыш материала и тактические удары.

## Формат данных
`id`, `fen`, `side`, `solution`, `difficulty`, `theme`, `reward`.

## Контент
Разрешено использовать задачи из книг Сергея Иващенко («Учебник шахматных комбинаций 1а», «1б» и далее) и переводить их в универсальный data-format.

## Архитектурное правило
Puzzle engine не зависит от конкретной книги; позиции импортируются пакетами и валидируются шахматным движком.
