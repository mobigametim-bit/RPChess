# 01 — Core Game Loop

1. Новый забег: персонализированный король, стартовый небольшой отряд, золото и припасы.
2. После каждой завершённой встречи генерируются **3 случайных следующих пути**.
3. Игрок выбирает один из: `PUZZLE`, `SKIRMISH`, `BATTLE`, `EVENT`, `SETTLEMENT`.
4. Два остальных варианта исчезают; карта заранее в глубину не строится.
5. Списываются припасы, разрешается выбранная встреча, применяются мгновенные последствия.
6. Генерируются следующие три пути.
7. Run продолжается, пока жив персонализированный король и отряд способен продолжать.

## Конец забега
- смерть персонализированного короля;
- полная потеря пригодного roster;
- истощение через последовательные переходы без припасов.
