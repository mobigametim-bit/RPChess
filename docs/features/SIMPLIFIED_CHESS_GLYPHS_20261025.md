# «Упрощённый» режим шахматных фигур

**Ветка:** `feature/simplified-chess-glyphs-20261025`, от production `main`. Независимо от PvP Турнира PR #164.

## Поведение
- Настройки → чекбокс **«Упрощённый режим»** / **Simplified mode**.
- По умолчанию выключено: используются обычные спрайты, включая именных героев и расы.
- При включении **только на игровых досках** (Классические шахматы, Битва, Стычка, Караван, Арена, Тренировка) вместо иллюстраций показываются стандартные Unicode chess symbols: белые — сплошные светлые силуэты ♟ ♚ ♛ ♜ ♝ ♞ с тёмной обводкой; чёрные — те же сплошные силуэты ♟ ♚ ♛ ♜ ♝ ♞ с тёмной заливкой. Настройка влияет на обе стороны.
- Режим переключается без перезапуска партии, автоматически применяется после нового запуска и сохраняется в существующем `rpchess.reboot.v1.settings`. Сохранённые позиции, характеристики и идентификаторы именных фигур не изменяются.
- При превращении пешки глиф мгновенно меняется в соответствии с выбранной ролью; в модальном окне превращения тоже показываются глифы.
- Перетаскивание мышью или пальцем показывает глиф вместо арта. В упрощённом режиме иллюстративные анимации перелётов отключены, чтобы не показывать старые картинки во время хода. Сами ходы, выбор и подсветка сохраняются.
- **Портреты героев, карточки, награды и ассеты вне шахматных досок не меняются** — сохраняется идентификация персонажей.
- Шах, полная/частичная связка, подсказки артефактов остаются доступными: DOM изображения фигур остаётся для сохранённой логики и выбора, скрывается только визуально.

## Приёмка
- Переключить настройку RU/EN, выключить и включить прямо в партии, перезагрузить страницу, убедиться в сохранении.
- Сыграть несколько ходов и провести мышью / пальцем, проверить цвет двух сторон.
- Проверить превращение именной пешки в роли ферзь/ладья/слон/конь, возвращение из сохранения.
- Проверить по мобильным/планшетным форматам и на разных игровых досках.
- Прогнать `RPCHESS_BROWSER_TEST=simplified-pieces-browser.cjs npm run test:browser` + исходный `npm run gate:local`.
- Не сливать в main до ручной приёмки.
