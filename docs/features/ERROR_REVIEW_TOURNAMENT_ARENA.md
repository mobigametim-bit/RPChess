# Разбор ошибок игрока — только Турнир и Арена

**Статус:** проектирование следующего этапа. В этой работе реализуется защищённый PvP-рейтинг; анализ партий ещё не включён в UI.

## Область действия
- **Турнир:** анализ завершённого матча PvP по серверной истории UCI и исходной FEN. Доступен только участникам партии после завершения. Нельзя помогать во время живого рейтингового матча.
- **Арена:** анализ завершённого боя против ИИ по локальной истории ходов и позиции.
- **Путешествие, Стычка, Караван и другие дорожные карты:** **не показывать разбор ошибок, задания на основе ошибок или автоматические обучающие подсказки**. Это явное продуктовое ограничение.

## Контракты
1. Хранить режим, итог, стартовую FEN, историю UCI, время и ID партии. Выделять оригинальную последовательность из актуального движка, а не переписывать её ИИ.
2. После окончания партии (не во время PvP) оценивать только ходы игрока через шахматный анализатор. Классифицировать зевок/ошибку/неточность по разнице оценок с учётом позиции; при отсутствии надёжного анализа **не выдумывать оценку хода**.
3. Предлагать 1–3 самых полезных эпизода; воспроизведение позиции перед ошибкой, рекомендация лучшего продолжения и «попробовать ещё раз» как легальное упражнение.
4. Привязать результат к партии и версии анализатора, чтобы повторный просмотр не пересоздавал задания или награды. Не менять PvP Elo задним числом.
5. На мобильном экране запускать анализ по запросу после партии; не блокировать результат, сохранить существующий UI и переключатель Fantasy/обычные фигуры.
6. Вывод RU/EN, корректная обработка шаха, мата, рокировки, превращения и взятия на проходе.

## План встраивания
- Общий аналитический интерфейс `analyseFinishedGame({mode,initialFen,moves,result})` **только** для `mode==='tournament'||mode==='arena'`.
- Адаптер Турнира читает утверждённую сервером партию; адаптер Арены читает завершённый PvE-протокол. Игровые правила и Elo от этого модуля не зависят.
- Первая поставка: просмотр ошибок и повтор позиции **без новых наград**. Следом тематические задачи по повторяющимся слабым сторонам.
- Тесты: режимная изоляция (ни одного вызова анализа из Путешествия), корректный UCI/FEN, отсутствие подсказок во время PvP, восстановление на mobile, idempotency.
