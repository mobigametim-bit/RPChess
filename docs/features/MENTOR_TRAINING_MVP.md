# Тренировка с наставником — первая итерация

Статус: кандидат в ветке feature/mentor-training-mvp-20261107. Не переносить в main без ручной приёмки.

## Цель

Играбельная локальная учебная партия с 12 уровнями (400–2600 Elo), мгновенной оценкой Stockfish, знаками ?! / ? / ?? на последней фигуре и возможностью отката, просмотра и продолжения с другой линии.

## UX

- Подготовка: 6 пар наставников по типам Пешка / Конь / Слон / Ладья / Ферзь / Король. Художественные фигуры и расовые ассеты из существующего каталога. Без лишних описательных надписей.
- Выбор стороны: белые, чёрные, случайно.
- Бой: журнал SAN слева, квадратная доска по центру, текст наставника справа. На вертикальном экране доска занимает ширину, журнал открывается отдельной кнопкой.
- Назад / Вперёд: один полуход. При новом легальном ходе из прошлой позиции старое продолжение отбрасывается. Восстановление всей последовательности UCI сохраняет правила повторения и 50 ходов.
- Повторный просмотр уже оцененного хода не вызывает повторного анализа.
- Русский и английский интерфейсы, локальная автозапись в отдельный ключ без касания VK/Cloud Save/GamePush прогресса.

## Движок и оценки

- Соперник: существующий ChessAIAdapter (Stockfish 18 lite) с 12 принятыми профилями силы.
- Качество хода: отдельный неослабленный StockfishReviewEngine; 260 мс на позицию, надёжность от depth 5; пороги 65 / 120 / 250 cp, как в существующем finished-game-review. Нет ложной отметки, если оценка недостаточно надёжна.
- Результаты анализа привязаны к конкретному полуходу, кэш оценок к FEN.
- Первую итерацию сопровождают нейтральные локальные пояснения. Они не подсказывают лучший ход и не выдумывают тактических причин.
- Gonka API / DeepSeek / Cloudflare API-Worker намеренно не подключены до следующей итерации.

## Сохранность

Не менять Arena, Tournament, Путешествие, рейтинг, награды, D1 и конфигурации Cloudflare Workers. Публикация только на изолированном статическом preview.

## Проверки и приёмка

- Node: 12 уровней, повторение позиции, возврат, пересоздание линии, проверка классификации.
- Chromium: каталог 12 наставников, настоящая партия со Stockfish за обе стороны, назад/вперёд, создание новой линии, 1280×800 и 390×844, отображение и открытие журнала.
- После успешного Actions запуска проверить отдельную ссылку на Cloudflare Preview вручную.

## Итерация UI 2 — приближение к Турниру

- Горизонтально доска занимает всю высоту viewport (если физически помещаются две компактные панели); поверх доски нет заголовка и статуса.
- Клетки используют white.png/black.png расы выбранного наставника через единый raceBoardTiles.
- Один общий переключатель упрощённых фигур через makeToggle(), синхронизированный с настройками RPChess; на вертикальном экране доступен под доской.
- Общий attachPieceDrag, стабильные DOM-клетки во время pointer gesture, прямой контроль легальности владельцем режима.
- Анимация перемещения 290 мс, взятия 240 мс и накладка связки через applyPinIce(snapshot), как в Турнире.
- Потерю cp продолжаем считать внутри анализатора, но больше не показываем числом пользователю.
