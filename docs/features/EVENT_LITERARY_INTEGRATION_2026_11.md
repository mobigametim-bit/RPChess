# Литературные результаты событий — интеграция для ручной приёмки

**Статус:** реализовано в `feature/event-literary-outcomes-integration-2026-11`, PR #200 (draft), **`main` не изменён**.
**Демо:** https://rpchess-event-literary-preview.mobigametim.workers.dev/

## Объём

- 500 событий E001–E500, 2 114 базовых решений.
- 3 388 основных исходов (успех/неудача) + 376 индивидуальных резервных исходов = **3 764 уникальных текста**.
- 537 именных вариантов Events v5 наследуют художественный текст источника по `sourceChoiceId`.
- Исходные авторские JSON и Markdown находятся в ветке `docs/event-outcomes-literary-ru-2026-11`; runtime-модули `game/js/events/literary-outcomes-01..08.mjs` сгенерированы из **финальных** JSON без переписывания редакторских строк. Нет дубля story/action/effects внутри нового игрового каталога.

## Контракт поведения

1. `events-core.mjs` продолжает быть единственным источником шансов, стоимости, RNG, боя и состава отряда.
2. После применения эффектов сохраняются структурные `currentEvent.outcome.effectReceipts`: фактическая разница ресурсов, имена/ID реально пострадавших или нанятых бойцов, отсутствие подходящей цели, резервное золото за недоступного рекрута, бой. Старые `outcome.notes` сохраняются без изменения.
3. `event-literary-outcome.mjs` использует `outcome.choiceId`, `sourceChoiceId`, сохранённый `outcome.success` и **только сохранённые receipts**; никогда не повторяет бросок и не пытается вычислить случайного героя второй раз.
4. Резервные варианты выбираются по реальному `recruit.unavailable` и `wound/death.skipped`. Неполные/старые сохранения без receipts показывают только прежние достоверные `notes`.
5. Русская версия показывает художественный результат между статусом и фактическими последствиями. Английская версия пока **не содержит переведённого литературного каталога**: она использует прежний вывод результата и не показывает русскую прозу. Полный EN-перевод требует отдельного решения и редактуры.
6. Центрированная панель результата сохраняет шрифт BrahmsGotischCyr, цвета, фон текущего события, resource icons, кнопки «Продолжить» / «К битве» / «К стычке», landscape-адаптацию.
7. Ранее согласованные исправления **E037.3** (ранение здорового non-King +50 Gold, блокировка при отсутствии цели), **E084.2** (+20 Gold за успешное запугивание) включены в этот PR; **E044.1** остаётся залогом -12/+12 Gold. См. `docs/features/EVENT_LEGACY_EFFECTS_PATCH_2026_11.md`.

## Автоматические проверки

- Расширены существующие `tests/events.cjs`, `tests/events-browser.cjs` и связанные исходные контрактные проверки: комплектность, уникальность, 537 v5, резервные ветки, сохранённые receipts, настоящие имена, RU/EN, перезагрузка, центрирование.
- Процедура `npm run build` включает новый резолвер и все восемь модулей в `dist`.
- Превью собирается и публикуется отдельным Workflow `.github/workflows/event-literary-preview.yml`, на собственном Cloudflare Worker, без затрагивания VK / Yandex / GitHub Pages.
