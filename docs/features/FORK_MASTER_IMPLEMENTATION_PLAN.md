# Мастер вилок / Fork Master — план внедрения

Дата: 2026-10-02. Статус: реализовано и автоматически проверено; приватная сборка опубликована; ожидается ручная приёмка.
База: main `e6566ea0184a533bff6c6069f8435731d6b403c8`.

## Согласованные правила
- Артефакт действует в одном выбранном бою. Путешествие: Битва, Стычка, Караван; Арена: бой с ботом.
- Выбор своей фигуры с двумя или более атакованными противниками включает синхронную плавную пульсацию их силуэтов. С одной целью пульсации нет.
- Зелёный: после предполагаемого взятия цели нет законного ответного взятия атакующей фигуры. Красный: такое ответное взятие есть. Это не оценка выгодности размена.
- Учитываются препятствия, фигуры на пути, связки и безопасность собственного короля. Вражеский король учитывается как цель вилки, а подсветка шаха сохраняет приоритет.
- Для каждого допустимого хода выбранной фигуры проверить позицию после хода, до ответа соперника. Если именно перемещённая фигура атакует минимум двух противников, отметить клетку.
- **На такой клетке золотая двойная стрелка ЗАМЕНЯЕТ обычный кружок доступного хода, а не рисуется рядом.** На остальных клетках остаются обычные маркеры. Для взятия, создающего вилку, двойная стрелка также становится единственным маркером назначения. Клик по клетке выполняет обычный ход.
- Просмотр будущих целей, hover-прогноз, силуэт перемещаемой фигуры и удержание пальца не добавляются.
- SVG/CSS для стрелки и пульсации; генерация изображений не нужна. При уменьшении анимаций свечение постоянное.
- Иконка: `game/assets/heroes/temur_wind/ability_icon.png` (конь и две стрелки), копия в `game/assets/artifacts/fork_master.png`; исходник героя не меняется.
- Название RU: «Мастер вилок», EN: «Fork Master». Описание RU: «Помогает находить вилки: показывает двойные атаки и ходы, которыми их можно создать. Зелёные цели — без ответного взятия, красные — с возможностью ответного взятия».
- Начальная цена: 15 золота за заряд в Путешествии, 7 Осколков чести за матч в Арене. Один заряд расходуется один раз, эффект восстанавливается при продолжении боя.

## Порядок реализации
1. Добавить стабильный ID `tactics.fork_master`, RU/EN имя и описание, цену и самостоятельную иконку; зарегистрировать иконку в ARTIFACT_FILES и проверить сжатие.
2. На копиях позиции реализовать расчёт текущих целей и законных ответных взятий, не изменяя доску, историю ходов, turn, права рокировки и реальные допустимые ходы.
3. Рассчитать ходы для создания вилки всеми типами фигур, включая взятие, en passant и превращение. Для превращения клетка отмечается, если хотя бы один допустимый вариант даёт вилку; результат зависит от выбранного превращения.
4. Пульсировать именно силуэты фигур через альфа-маску используемого изображения; сохранить глифы, заморозку, шах, препятствия и читаемость фигур.
5. Заменить кружки/маркеры на клетках вилки двойной SVG-стрелкой. Не перехватывать клики и не добавлять новый пользовательский жест.
6. Подключить Битву, Стычку, Караван и Арену; очистка при снятии выбора/конце боя, пересчёт при изменении позиции. На ходе бота подсказки ходов не показывать.
7. Подключить существующие случайные предложения (до трёх артефактов плюс «Без артефакта»), магазин, награды Каравана и покупку Арены. Проверить все места с фиксированным числом предметов.
8. Проверить старые локальные/облачные сохранения, новые заряды, выбранный эффект, расход без повторения, покупки и прерванный бой. Схему сохранений не менять.
9. Выполнить unit, localization, save/economy и production build; Chromium — все четыре режима, реальные маркеры/маски/клики, мобильный экран, шах, reduced motion и восстановление.
10. Сохранить код в feature-ветку и draft PR, обновить статусы GitHub/Notion, опубликовать приватную играбельную сборку Sites и передать владельцу на ручной тест. Слияние в main и основной ручной деплой — после приёмки.

## Критерии приёмки
- [x] Две и более цели пульсируют правильными цветами; одна цель не пульсирует.
- [x] Связанный защитник, открывшаяся линия и ответ королём корректно влияют на цвет.
- [x] Стрелка заменяет кружок, обычные ходы и взятия сохраняются.
- [x] Король + другая цель образуют вилку; красный шах имеет приоритет.
- [x] Подсказки не меняют игру и работают с препятствиями/всеми фигурами/обоими цветами.
- [x] RU/EN, цены, сжатие иконки и мобильный интерфейс проверены.
- [x] Старый прогресс читается; новый предмет и активный эффект сохраняются локально и в облаке.
- [x] Играбельная сборка передана на ручную приёмку.
