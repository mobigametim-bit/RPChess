# Устанавливаемая PWA-версия RPChess

**Статус:** отдельная ветка `feature/pwa-installable-20261104`. До ручной приёмки владельца изменения не сливаются в `main`.

## Цель

Игрок открывает HTML5-версию «Герои Шаха и Мата» через HTTPS, добавляет на главный экран Android/iPhone и запускает её с иконки в отдельном окне без адресной строки браузера.

Это **не APK** и не публикация в Google Play / App Store. Стандартные игровые режимы, сохранения и сетевые API остаются прежними.

## Поддержка ориентации и платформ

- **Вертикальная и горизонтальная ориентации** уже работают в игре и обе остаются доступными. Манифест: `orientation: "any"`; принудительное переключение экрана не вводится.
- PWA-регистрация разрешена только для самостоятельных адресов GitHub Pages, Cloudflare acceptance preview и localhost. В iframe / VK Mini Apps и на чужих доменах Service Worker не регистрируется.
- Рабочий URL после принятия: `https://mobigametim-bit.github.io/RPChess/`. Отдельный URL для ручной проверки: `https://rpchess-portrait-ui-preview.mobigametim.workers.dev/`.

## Реализация

- `game/manifest.webmanifest`: русское имя, `start_url`/`scope` = `./` (одинаково корректны корень Cloudflare и подпапка `/RPChess/` GitHub Pages), `display: standalone`, `orientation: any`.
- `game/pwa/icon-source.png`: исходная иконка короля в золотых элементах с синими кристаллами, получена из предоставленного пользователем PNG 512×512, оптимизирована для хранения. `scripts/pwa-icons.cjs` формирует в `dist/icons/` настоящие PNG: 192×192, 512×512, маскируемую 512×512 с безопасными полями и `apple-touch-icon` 180×180. Никакой новой npm-зависимости.
- `game/index.html`: тег `rel=manifest`, значок Apple, цвета и отдельный модуль регистрации.
- `game/js/pwa-install.mjs`: безопасное подключение Worker только в самостоятельном веб-окне поддерживаемых хостов.
- `game/service-worker.js`: небольшой кэш служебных ресурсов, всегда свежая навигация через сеть и офлайн-экран при полном отсутствии подключения. **Не** кэширует шахматные данные, финансы, запросы Турнира, VK Bridge, фоновые арты или Stockfish; не вмешивается в игровые механики.
- `game/offline.html`: объяснение, что для запуска нужен интернет, и кнопка повторной попытки.
- `scripts/build.cjs`: включение PWA-файлов и иконок в итоговый `dist`.
- Проверки расширяют существующие `tests/brand-logo.cjs`, `tests/portrait-key-scenes-browser.cjs` (manifest, PNG, реальный scoped Service Worker на мобильной ширине) и workflow Cloudflare Preview.

## Ручная приёмка

1. Открыть тестовую сборку **в браузере** (не внутри VK).
2. **Android / Chrome:** меню браузера → «Установить приложение» или «Добавить на главный экран»; проверить иконку и запуск отдельным окном.
3. **iPhone / Safari:** «Поделиться» → «На экран „Домой“» → добавить веб-приложение; проверить иконку и запуск.
4. Проверить обе ориентации, новую игру, продолжение локального сохранения, Арену и сетевой Турнир.
5. Проверить обновление страницы с доступным интернетом и офлайн-заглушку без него. **Полноценная офлайн-игра намеренно не предусмотрена на этом этапе.**
6. После подтверждения пользователя отдельно слить в `main` и проверить установку уже из основного адреса GitHub Pages.

## Ограничения и обновления

- Системный пункт установки и оформление режима `standalone` зависят от браузера/ОС; принудительное включение полного fullscreen или блокировки ориентации отсутствует.
- PWA с Cloudflare и PWA с GitHub Pages — **два отдельных происхождения** и две отдельные установки. После публикации production устанавливать следует с GitHub Pages.
- Service Worker не отключает интернет и не меняет правила хранения сохранений. Офлайн-заглушка показывается только если навигация действительно не смогла загрузиться из сети.
- При изменении закэшированных служебных файлов в следующем релизе нужно изменить версию `rpchess-pwa-shell-1` в Service Worker.
