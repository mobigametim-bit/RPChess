# Исправление трёх особых событий — ноябрь 2026

**Статус:** реализовано в feature-ветке, ожидает автоматической и ручной приёмки; `main` не изменён этим исправлением.

## Принятые решения

- **E037.3, «Красная печать».** 100% успех: автоматически выбирается один здоровый персонализированный герой, кроме Короля; он получает тяжёлое ранение, после этого добавляется 50 Gold. При отсутствии подходящего здорового non-King героя выбор заблокирован до разрешения события; выдача золота невозможна. Выбор цели остаётся детерминированным по уже используемому алгоритму, повторное применение события не допускается.
- **E044.1, «Весы суда».** Без изменений: уплата залога 12 Gold и его возврат (+12 Gold), итоговая разница 0; отдельной персистентной механики «безопасный проход» нет.
- **E084.2, «Гоблин с картой».** 70% успех: выдаётся +20 Gold, карта существует только как сюжетная деталь, не как инвентарный предмет. При неудаче запускается прежняя Стычка.

## Реализация

- `game/js/events/event-data-04.mjs`: исправлен токен `E037.3` на распознаваемое `случайный non-King wound, +50 Gold`.
- `game/js/events/event-data-09.mjs`: `E084.2` теперь использует распознаваемый токен `+20 Gold`.
- `game/js/events-core.mjs`: перед выдачей крови проверяется наличие здорового non-King; существующий обработчик ранений сохраняет статус и не затрагивает Короля.
- `tests/events.cjs`: расширены существующие проверки для всех трёх случаев, успешной/неуспешной ветки, повторного разрешения события.

Художественные версии E037.3 и E084.2 обновлены **отдельно** в `docs/event-outcomes-literary-ru-2026-11`, включая JSON, Markdown и редакторские overrides. Они войдут в runtime при плановой интеграции полного литературного пакета. Старый генератор `OUTCOME_DRAFT_GENERATOR.js` запускать нельзя: он может затереть индивидуальную редактуру.

## Критерии ручной приёмки

1. E037.3 с хотя бы одним здоровым героем кроме Короля: ровно один получает тяжёлое ранение, золото +50.
2. E037.3 с одним Королём либо со всеми остальными ранеными: кнопка недоступна, награда не выдаётся.
3. E044.1 при достаточном золоте: залог возвращается, нет дополнительного боя.
4. E084.2 при успешном броске: +20 Gold; при провале: Стычка.
5. После перезагрузки результат не применяется повторно.

**Запрещено сливать в `main` без ручного подтверждения владельца.**
