# RPChess asset provenance

Updated: 2026-09-15

This file records the known origin of production visual assets in RPChess for release/moderation bookkeeping. It is a provenance record, not a substitute for the individual licenses of third-party components listed in `THIRD_PARTY_NOTICES.md`.

## Production visual assets

The production visual assets created specifically for RPChess — including character art, chess-piece art, portraits, scene backgrounds, event backgrounds, UI illustrations, icons, map/node art, board visuals, overlays, VFX source art and promotional/gameplay artwork stored in the project — were generated specifically for RPChess with ChatGPT/OpenAI image-generation tools from prompts and iterative art-direction supplied by the RPChess project owner.

These assets were not intentionally imported from a commercial stock-art pack or another game's asset library. Where a third-party component or externally sourced work is used, it must be listed separately in `THIRD_PARTY_NOTICES.md` or another explicit provenance/license record.

## Third-party/non-generated items

Known non-RPChess-original/generated components are tracked separately, including:

- `BrahmsGotischCyr.otf` — SIL OFL 1.1; attribution recorded in `THIRD_PARTY_NOTICES.md`.
- Stockfish runtime — GPLv3; source/license handling recorded in `THIRD_PARTY_NOTICES.md`.
- Lichess Open Database Puzzles — CC0; source recorded in `THIRD_PARTY_NOTICES.md`.
- `game/SFX/win_fanfare.mp3` — derived from `_MC5_`, `Short Brass Fanfare 1.wav`, Freesound sound 524849, CC BY 4.0; attribution recorded in `THIRD_PARTY_NOTICES.md` and `CREDITS.md`.

## Future additions

Before any new third-party visual, font, audio pack, dataset or engine is added to a release candidate, record its source and commercial-use/license basis. Newly generated RPChess visuals should remain identifiable as project-specific generated production art in the repository asset inventory.
